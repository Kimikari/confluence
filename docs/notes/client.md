# Unity client foundation (`client/`)

Unity 6000.6.4f1 project that renders Confluence.Core data and collects input. It never decides rules
(docs/ARCHITECTURE.md; DECISIONS D-002, D-003). Everything is built at runtime from code: the only scene is
`Assets/Scenes/Bootstrap.unity` (generated by `ProjectConfigurator`, one GameObject with `Bootstrap`), there are
no prefabs, and pressing Play in any scene also boots the app (`Bootstrap.EnsureBootstrap`).

## Daily use

| Task | Command |
| --- | --- |
| Sync libraries + catalogue into the project | `powershell -ExecutionPolicy Bypass -File tools/sync-unity.ps1` |
| Build the player (sync first) | `powershell -ExecutionPolicy Bypass -File tools/build-client.ps1` |
| ... plus EditMode tests and a smoke run | `powershell -ExecutionPolicy Bypass -File tools/build-client.ps1 -Tests -Smoke` |
| Re-apply project configuration | `... tools/build-client.ps1 -Configure` (or menu *Confluence > Configure Project*) |

`build-client.ps1` writes `out/unity-<step>.log`, fails on a non-zero exit, `error CSxxxx`, "Scripts have
compiler errors", a licensing/"another instance" message, or a missing success marker
(`[Configure] Project configured`, `[Build] RESULT Succeeded`). Tests write `out/unity-editmode.xml`. The player
goes to `out/client/Confluence.exe` (development, Mono, x64). Close any editor that has `client/` open first.

Player switches (`App/CommandLineOptions.cs`; Unity's own `-screen-*` / `-logFile` pass through):

- `-arenaPreview` open the sample arena preview instead of the menu; `-previewView fly|walk|overview`;
  `-previewTime <s>` initial combat clock (e.g. 70 shows the boundary mid-contraction).
- `-menuPanel play|settings|codex|training` open that menu entry at start.
- `-screenshot <path>` PNG written 1.5 s before `-quitAfter` (or at 3 s); `-quitAfter <s>` exits with code 1 if
  any error/exception was logged (`App/SmokeTestDriver.cs`). Smoke runs use in-memory settings.

Smoke example: `out/client/Confluence.exe -arenaPreview -screenshot out/client-shot.png -quitAfter 8
-screen-width 1280 -screen-height 720 -screen-fullscreen 0 -logFile out/client-smoke.log`.

Preview keys: Tab overview, F walk/fly, WASD, Space jump/up, Ctrl/C down, Shift fast, Q/E or right-drag rotate
(overview), wheel zoom, P pause clock, `[` `]` scrub 5 s, Backspace reset clock, Esc leave.

## Synced binaries (decision)

`tools/sync-unity.ps1` Release-builds every `src/*/*.csproj` targeting netstandard2.1, copies each
`Confluence.*.dll` + `.pdb`, the netstandard DLLs of their NuGet references (LiteNetLib 2.1.4 always), into
`Assets/Plugins/Confluence/`, and the catalogue into `Assets/StreamingAssets/`. **Binaries and the catalogue copy
are gitignored (`client/.gitignore`); their `.meta` files are committed** so GUIDs are stable. A missing meta
is written from a template whose GUID is the MD5 of `Confluence.Client/<folder>/<file>`, so a new library gets
the same GUID on every machine. Files are rewritten only when their hash changes. The build script always
syncs first; an EditMode test fails if the StreamingAssets catalogue differs from `docs/confluence/`.
The editor can also fall back to the repository catalogue (`CatalogueService.ResolvePath`).

## Project configuration (`Assets/Editor/ProjectConfigurator.cs`, idempotent)

Company/product "Confluence", version 0.1.0, linear color space, .NET Standard 2.1 API level, Mono backend,
Input System package as the only active input handling (serialized `activeInputHandler = 1`; restart the editor
after it changes), windowed 1600x900 resizable, no splash. URP: `Assets/Settings/ConfluenceUniversalRP.asset` +
`ConfluenceUniversalRenderer.asset` assigned in Graphics and every Quality level (HDR, MSAA 4x, 2048 shadow
map, 4 cascades, 90 m), URP global settings created. Base materials `Resources/Materials/ArenaLit`,
`ArenaLitTransparent`, `ArenaUnlitTransparent` exist so the build includes their shader variants; runtime
materials copy them and only change textures/colors/floats (never keywords). `BuildScript.BuildWindowsPlayer`
verifies this configuration before building.

## Runtime architecture (`Assets/Scripts`, asmdef `Confluence.Client`)

- `App/Bootstrap` creates settings (PlayerPrefs, or memory in smoke runs), `CatalogueService`, `UiShell`,
  `AppStateMachine`, a menu camera, and routes states to screens. `App/ClientContext` bundles the services.
- `App/AppStateMachine`: explicit transition table. Boot -> MainMenu | ArenaPreview; MainMenu -> Connecting |
  Training | Codex | ArenaPreview; Connecting -> Lobby; Lobby -> Shop; Shop -> Draft | Alcove (draft only on
  augment rounds, spec L45); Draft -> Alcove; Alcove -> Duel (the only way into combat, L46-L47); Duel ->
  Results; Results -> Shop | Lobby (L49); every state but Boot can return to MainMenu. Lobby..Results are
  `UI/PlaceholderScreen`s whose buttons are exactly the legal targets, until Confluence.Net provides a session.
- `Content/CatalogueService` loads the catalogue unchanged through `Confluence.Core.Content.Catalogue.Load` on a
  worker thread and publishes on the main thread (`Poll`). `LoadNow` for tests.
- UI Toolkit from code: `UI/UiShell` (PanelSettings in code, scale with screen 1920x1080, three layers:
  screen, HUD, overlay), `UI/Ui` element factory, `Resources/UI/Confluence.uss` + `ConfluenceTheme.tss`.
  Screens: `BootScreen`, `MainMenuScreen` (Play card with host/port/name validated by `PlayProfile`, Training,
  Codex, Collection/Replays disabled, Settings, Quit), `SettingsPanel` (FOV 80-110, sensitivity, invert Y,
  master/music/effects/voice), `CodexScreen` (catalogue browser by type with filter and raw fields),
  `ArenaPreviewHud` (biome, environment rule, camera mode, clock, material legend with plain descriptions).
- `Settings/ClientSettings` clamps every value; `Settings/PlayProfile` host/port/name.
- `Arena/ArenaRenderer` builds any `ArenaLayout`: solids (`ArenaMeshes.Box` / `.Ramp` match YawBox/RampShape
  exactly, UVs in meters), surface materials by `Surfaces.ForSolid` (material name, then flags) and
  `Surfaces.ForPatch` (largest unit count), patch decals (opacity scales with units), prop placeholders with
  category glyph billboards (`PropPlaceholder`, catalogue `PropDef` mass/category), spawn ward volumes and
  facing markers, final-floor ring, `BoundaryView` (wall + ground line rewritten from
  `BoundaryContour.RadiusAt(yaw, t)`), overhead light + light shafts (`ArenaLighting`).
  `SetCombatTime(t)` drives the contour and final-cover warning (83 s) / retirement (85 s).
- `Arena/SampleLayouts` — **temporary debug tool**: a hand-built 32 m Raincourt layout with 180-degree
  rotational symmetry (MirrorIds), alcoves, center floor, pillars, retiring hedge cover, metal/glass/wood/porous
  cover, a 23-degree ramp to a 1.5 m platform, water/sand/growth/conductor patches, five prop pairs, light shafts
  and an even-harmonic contour. Not validated; replace with Confluence.Arena's generator.
- Cameras: `FirstPersonRig` (root at feet, camera at `GlobalRules.Movement.StandingEyeHeight`; walk via
  `PreviewWalker` or free fly), `ArenaOverviewCamera` (orbit, tilt 35-89.5 degrees, default 72), `PreviewInput`
  (Input System actions built in code, raw mouse delta).
- `Mapping/CoreSpace`: Core uses Unity axes, so positions and yaw map directly
  (`Quaternion.Euler(0, yaw, 0)`). **Pitch is the one flip**: Core pitch is elevation (positive looks up,
  `CMath.ForwardFromYawPitch`), Unity euler X is positive-down, so `eulerX = -pitch`. Tested.

## Interpretations (spec lines)

- L371 "field of view 80 through 110": horizontal FOV (PC shooter convention), converted to Unity's vertical FOV
  for the current aspect every frame; default 95.
- L369 sensitivity with acceleration off: look = raw counts x sensitivity x 0.022 deg; range 0.1-10, default 2.
- L329 "rotatable top-down preview": an orbit camera defaulting to 72 degrees of tilt (adjustable to straight down)
  so elevation stays readable; the HUD lists diameter, environment rule, and plain material descriptions.
- L371 "palettes that preserve material patterns": each surface kind is a distinct grayscale luminance pattern
  multiplied by its tint, so a palette change cannot erase identity (EditMode test compares all pairs).
- L320 "standardized overhead lighting": one fixed directional light (pitch 68, yaw 35, intensity 1.35), fixed
  ambient, and spot lights for `LightShaft`s; identical for every arena.
- L678: `Solid.RetiresAtFinal` cover gets a hazard tint at 83 s and is hidden at 85 s; scrubbing back restores it.
- L306/L331 visible boundary: translucent striped wall 6 m tall plus ground line; contraction L48 via Core's contour.
- L341 lists Collection and Replays: shown disabled. Quit is added (not in L341) because the task requires it.
- L421: `Application.targetFrameRate = GlobalRules.Network.TargetFrameRate` (120).

## Tests (`Assets/Tests/Editor`, asmdef `Confluence.Client.Tests.Editor`)

32 EditMode tests: state machine edges (combat only from the alcove), command-line parsing, settings clamps and
persistence, catalogue load through Core and StreamingAssets freshness, Core/Unity yaw and pitch mapping,
surface classification and pattern distinctness, sample layout symmetry and rule limits, and the renderer
(one object per element, solids match boxes and materials, ramp mesh under the Core surface, boundary vertices on
`RadiusAt` while contracting, 83/85 s cover schedule, overhead light, legend order, rebuild, minimal layout).
Run: `Unity.exe -batchmode -nographics -projectPath client -runTests -testPlatform EditMode -testResults
out/unity-editmode.xml -logFile out/unity-editmode.log` or `build-client.ps1 -Tests`.
