# Unity client (`client/`)

Unity 6000.6.4f1 project that renders Confluence data and collects input. It never decides rules
(docs/ARCHITECTURE.md; DECISIONS D-002, D-003): duels, shops and drafts run on the shared libraries (Sim, Economy,
Arena), locally in the offline Laboratory and later on the server. Everything is built at runtime from code: the only
scene is `Assets/Scenes/Bootstrap.unity` (generated by `ProjectConfigurator`, one GameObject with `Bootstrap`), there
are no prefabs, UI Toolkit screens are built in code, and pressing Play in any scene also boots the app.

## Daily use

| Task | Command |
| --- | --- |
| Sync libraries + catalogue into the project | `powershell -ExecutionPolicy Bypass -File tools/sync-unity.ps1` |
| Build the player (sync first) | `powershell -ExecutionPolicy Bypass -File tools/build-client.ps1` |
| ... plus EditMode tests and the smoke screenshots | `powershell -ExecutionPolicy Bypass -File tools/build-client.ps1 -Tests -Smoke` |
| Only some smoke views | `... -Smoke -SmokeOnly shop,draft` (with `-SkipSync` to reuse the synced DLLs) |
| Re-apply project configuration | `... tools/build-client.ps1 -Configure` (or menu *Confluence > Configure Project*) |

`build-client.ps1` writes `out/unity-<step>.log`, fails on a non-zero exit, `error CSxxxx`, "Scripts have
compiler errors", a licensing/"another instance" message, or a missing success marker
(`[Configure] Project configured`, `[Build] RESULT Succeeded`). Tests write `out/unity-editmode.xml`. The player
goes to `out/client/Confluence.exe` (development, Mono, x64). Close any editor that has `client/` open first.

Smoke views (`-Smoke`, 1280x720 windowed, each `out/smoke/<view>.png` + `.log`, run fails if any error is logged):
`arena` (generated 32 m Raincourt in the overview with the generator panel and metrics; also copied to
`out/client-shot.png`), `sandbox` (Laboratory first-person duel, demonstration pilot striking the guarding dummy),
`shop` and `draft` (Laboratory round 1 with one demonstration purchase), `hud` (duel fast-forwarded to 78 s: boundary
contraction, judgement indicator).

Player switches (`App/CommandLineOptions.cs`; Unity's own `-screen-*` / `-logFile` pass through):

- `-arenaPreview` open the arena preview; `-previewView fly|walk|overview`; `-previewTime <s>` initial clock -5..90.
- `-arenaSeed <n>`, `-arenaRound <n>`, `-arenaDiameter 24|32|40|48`, `-arenaBiome BIO-nnn`: generator request for the
  preview and the Laboratory (default seed 7919, round 1, scheduled diameter, seeded biome).
- `-menuPanel play|settings|codex|training` open that menu entry at start.
- `-laboratory` open the Laboratory; `-labScreen setup|reveal|shop|draft|build|duel|results`, `-labRound <n>`,
  `-labWizard`/`-labOpponent WIZ-nnn`, `-labDuelTime <s>` fast-forward the duel to that combat time, `-labDemo`
  (demonstration pilot for the player, guarding dummy, one purchase in the shop).
- `-screenshot <path>`, `-quitAfter <s>` (`App/SmokeTestDriver.cs`): screens with background work hold the
  screenshot (`SmokeTestDriver.Hold`) until ready plus 1.5 s; exit code 1 if any error was logged.

Preview keys: Tab overview, F walk/fly, G generator panel, WASD, Space jump/up, Ctrl crouch/down, Alt dodge, Shift
sprint/fast, Q/E or right-drag rotate, wheel zoom, P pause clock, `[` `]` scrub 5 s, Backspace reset clock, Esc leave.
Duel keys (spec L84 defaults, `Input/DuelInput.cs`): WASD, mouse, LMB cast, RMB guard, Shift sprint, Space jump, Ctrl
crouch, Alt dodge, 1-6 or wheel slot, F melee, Q signature, E active, X consumable, T recast, R cast modifier, Z/C
modifiers A/B; Tab build panel, Esc Laboratory menu. Shop: 1-3 buy, Shift+1-3 reroll. Draft: 1-5 select,
Shift+1-5 reroll, P pass. Tab/arrows + Enter navigate every screen.

## Synced binaries (decision)

`tools/sync-unity.ps1` Release-builds every `src/*/*.csproj` targeting netstandard2.1, copies each
`Confluence.*.dll` + `.pdb`, the netstandard DLLs of their NuGet references (LiteNetLib 2.1.4 always), into
`Assets/Plugins/Confluence/`, and the catalogue into `Assets/StreamingAssets/`. **Binaries and the catalogue copy
are gitignored (`client/.gitignore`); their `.meta` files are committed** so GUIDs are stable. A missing meta
is written from a template whose GUID is the MD5 of `Confluence.Client/<folder>/<file>`. The runtime asmdef
references every plugin automatically; the test asmdef lists Core, Arena, Economy, and Sim explicitly.

## Project configuration (`Assets/Editor/ProjectConfigurator.cs`, idempotent)

Company/product "Confluence", version 0.1.0, linear color space, .NET Standard 2.1 API level, Mono backend,
Input System as the only active input handling, windowed 1600x900 resizable, no splash. URP assets in
`Assets/Settings/`, base materials `Resources/Materials/ArenaLit`, `ArenaLitTransparent`, `ArenaUnlitTransparent`
(runtime materials copy them and only change textures/colors/floats). `BuildScript.BuildWindowsPlayer` verifies it.

## Runtime architecture (`Assets/Scripts`, asmdef `Confluence.Client`)

- `App/Bootstrap` creates settings, `CatalogueService`, `UiShell`, `AppStateMachine`, a menu camera, and routes
  states to screens. `AppStateMachine`: Boot -> MainMenu | ArenaPreview | Laboratory; MainMenu -> Connecting |
  Laboratory | Training | Codex | ArenaPreview; Training -> Laboratory | ArenaPreview; Connecting..Results follow the
  round sequence (combat only from the alcove) and stay placeholders until Confluence.Net provides a session.
- `Arena/ArenaGenerationService` runs `Confluence.Arena.ArenaGenerator` (one shared generator per catalogue) on a
  worker thread and publishes on the main thread; `ArenaReportText` turns the release (attempt k of 8 or fallback)
  and the validator metrics into labelled lines. `ArenaRenderer` builds any `ArenaLayout` (unchanged), plus
  `SyncSolids(CollisionWorld)`: layout solids the duel destroyed are hidden and temporary solids are drawn while they
  exist. `Surfaces.PresentIn(layout)` lists the surface kinds before rendering (reveal screen).
- Arena preview (`App/ArenaPreviewController`, `UI/ArenaPreviewHud`, `UI/ArenaGeneratorPanel`): seed, round,
  diameter (24/32/40/48 or schedule) and biome (seeded or forced, filtered by size) pickers, Generate, release text
  with the FALLBACK flag, validator metrics and rejected attempts. Walk mode is `Movement/LocalMotor`: the Sim
  `CharacterMotor` stepped at 60 ticks/s by `Movement/TickClock` against `CollisionWorld.FromLayout`, interpolated
  between ticks (the basis of client prediction). `SampleLayouts` and `PreviewWalker` are gone.
- Laboratory (`Laboratory/`): `LaboratorySession` (plain C#) runs the round sequence on local Economy objects
  (reveal, 35 s shop with 600/500 income and the 100 winner bonus, 30 s draft on draft rounds, duel, results with
  Resolve) against a training dummy that never shops; `LaboratoryController` hosts it (setup screen, arena generation
  per round seed, overview camera for the reveal, tick-counted `PhaseTimer`s, Esc menu, Tab build panel).
  `SparringLayout` moves the two spawns onto the final floor 3.2 m apart with clear sight and a clear walking line
  (sandbox only). `DuelPilots`: `TrainingDummyPilot` (Idle, Guard, Strafe, Spar) and `DemoPilot`, both producing
  `PlayerInput` like a player. `LoadoutDuelSetup` maps a finalized `Loadout` to a `DuelPlayerSetup`.
- View models (`ViewModels/`): interfaces `IShopViewModel`, `IDraftViewModel`, `IBuildViewModel`,
  `IRoundRevealViewModel`, `IHudViewModel`, `IRoundResultsViewModel` (data classes in `ViewModelTypes.cs`), so the
  network layer can feed the same screens later. Offline implementations: `EconomyShopModel` (`EquipmentShop`),
  `EconomyDraftModel` (`AugmentDraft`: replacement slot, then confirmation listing augments that become dormant),
  `LoadoutBuildModel`, `RoundRevealModel`, `RoundResultsModel`, `DuelHudModel` (reads a `DuelWorld`).
- Presentation (`Presentation/`): `OfflineDuel` (local authoritative `DuelWorld`, `DuelInput` or a pilot, first-person
  camera at the interpolated motor eye, first-person focus), `FighterView` (capsule matching the hit capsule, visor,
  focus, 120-degree guard arc brighter in the perfect window, the committed melee sweep at the profile's reach and arc,
  toppled when defeated), `DamageNumbers` (only `DamageEvent`s the local player landed, spec L349),
  `OwnedEntityViews` (fields and summons from `OwnedEntityRegistry`), `ShapeMeshes`.
- UI Toolkit from code (`UI/`): `UiShell` (PanelSettings in code, 1920x1080 reference, `SetScale` from the interface
  scale setting), `Ui` factory, `Resources/UI/Confluence.uss`. Screens: Boot, MainMenu (Laboratory entry), Settings
  (FOV, sensitivity, invert Y, interface and text scale 75-150%, volumes), Codex, LaboratorySetup, RoundReveal, Shop,
  Draft, BuildPanel, DuelHud, Results, ArenaPreviewHud, placeholders.
- `Mapping/CoreSpace`: Core uses Unity axes; pitch is the one flip (`eulerX = -pitch`).

## Interpretations (spec lines)

- L371 FOV 80-110 is horizontal, converted per aspect; L369 look = raw counts x sensitivity x 0.022 deg.
- L329 rotatable top-down preview: orbit camera at 72 degrees default; the reveal renders it beside the panel.
- L371 palettes preserve material patterns (distinct grayscale pattern per surface kind).
- L320 standardized overhead lighting; L678 final cover warns at 83 s and retires at 85 s; L46-L47 wards only in the
  alcove phase (clock -5..0).
- L69 Laboratory: offered content is the whole catalogue (`ContentAvailability.All`, records need not be
  implemented), the opponent is a dummy, phase timers may be paused, the offline duel pauses under the Esc menu, and
  the sandbox may move spawns (`SparringLayout`). Every Laboratory screen carries the "unranked, modified" label.
- L84 bindings: Ctrl is left Ctrl; the Sim's `SwapFocus` (L106 equip/swap) has no default key in L84 and is unbound.
  Presses shorter than a tick are latched into the next command.
- L349 damage numbers: only authoritative `DamageEvent`s whose attacker is the local player (guarded hits show the
  guard outcome); no numbers for rule damage or unconfirmed shots.
- L347 status icons: text glyphs plus a bordered colour per class (control immunity, wet, damage over time,
  healing budget, hard control, slow); the healing budget (120/duel, L114) is always shown.
- L353 "an inactive component is labeled before purchase": shop cards say when an active would stay dormant
  (another active enabled, or a Sidearm-only activation). Capped components need equipment stat modifiers (later).
- L355 final statistics: health, mana, stamina, mana regeneration, movement, cooldown/cost reduction, refund,
  lifesteal, dash charges always, plus resistances when modified; raw -> effective shown when a cap applies.
- L44 major terrain = distinct module names; props = counts per prop definition; materials = `Surfaces.PresentIn`.
- L359 decisive sequence: the Sim's per-player event window as numeric lines; the narrated explanation needs the
  spell and reaction runtimes.
- Reveal/shop flow: in the Laboratory the opponent's "previous-round loadout" is the dummy's loadout after the last
  round (its issued gear in round 1).

## Tests (`Assets/Tests/Editor`, asmdef `Confluence.Client.Tests.Editor`)

65 EditMode tests. Foundation: state machine edges (combat only from the alcove, Laboratory reachable), command-line
parsing (preview, arena, Laboratory switches), settings clamps and persistence (incl. interface scale), catalogue load
and StreamingAssets freshness, yaw/pitch mapping, surface classification and pattern distinctness. Generator-driven
rendering: deterministic generation and release text, metrics, half-turn symmetry, the renderer on generated layouts
(one object per element, boxes, ramps, boundary on `RadiusAt`, 83/85 s cover, wards, light, legend, rebuild), walk
mode equals `CharacterMotor`, tick clock. View models: shop cards (tier, price, slot, effect, reroll), buy/reroll/sell
through the economy, spell swap keeps six, ready, dormant augments with missing requirements after a sale
(AUG-079/AUG-093), draft cards (rarity, rank, target, eligibility, transformation guarantee), selection, the
replacement + confirmation flow listing the dependent that becomes dormant, cancel/pass, build statistics, session
income/winner bonus/Resolve/draw, phase timers, loadout -> duel setup, HUD model in the alcove, combat statuses
(wet, burn, control immunity), boundary cue and judgement, HUD screen. Presentation: sparring spawns, a demonstration
duel landing confirmed hits on the guarding dummy, L84 default bindings, destroyed and temporary solids, owned fields,
reveal model from a generated arena.
Run: `build-client.ps1 -Tests` or `Unity.exe -batchmode -nographics -projectPath client -runTests -testPlatform
EditMode -testResults out/unity-editmode.xml -logFile out/unity-editmode.log`.
